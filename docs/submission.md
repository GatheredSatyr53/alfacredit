# Что отправить на приёмку

Основной материал сдачи — **ссылка на репозиторий с кодом**, в котором эксперты могут прочитать README, клонировать исходники, запустить Docker и пройти сценарий. Презентация дополняет решение; одна презентация не заменяет его.

1. Вставь ссылку `https://github.com/GatheredSatyr53/probiinik` в поле решения.
2. Укажи точный commit SHA выбранной версии backend (`git rev-parse HEAD`); frontend и ML уже закреплены в `scripts/start-demo.ps1`. Если форма позволяет приложить документ, эти сведения можно написать в нём.
3. Проверь доступ на чтение и клонирование. Если любой из трёх репозиториев станет приватным, предоставь жюри `alfa-hack-2026` доступ и к нему: скрипт скачивает frontend и ML из их репозиториев.
4. Приложи PDF-презентацию как продуктовый обзор, если у формы есть поле для дополнительных материалов. Видеодемо необязательно по разъяснениям организаторов.

После дедлайна изменения не учитываются; отправлять нужно идентификатор версии, существовавшей на момент дедлайна. Наличие локального стенда само по себе не даёт удалённым экспертам доступ: `localhost` работает только на машине, где запущен проект.

## Что уже находится в репозитории

- README и `docs/quickstart.md`: назначение, окружение, полный запуск и диагностика.
- `compose.demo.yaml`, `scripts/start-demo.ps1`: четыре сервиса и закреплённые frontend/ML.
- PRODUCT.md: исследование, влияние на решение, функции, скриншоты и ограничения.
- README: архитектурная схема. `docs/api.md`, `docs/openapi.json`: API/OpenAPI; `docs/requests.http`, `docs/postman_collection.json`: коллекции запросов.
- `docs/state-machine.md`, `docs/data-model.md`: состояния и данные.
- `docs/quickstart.md` и тесты: демо-учётки и сценарии.
- THIRD_PARTY_NOTICES.md и `docs/dependency-inventory.json`: сторонние компоненты, собственная модель, данные, симуляции и версии.
- `docs/requirements-coverage.md`: соответствие основной части ТЗ и границы подтверждённых проверок.

Проверка офисного ПК с 8 ГБ и запуск при полностью пустом Docker-кэше не заявляются как измеренные. Опубликованный внешний веб-стенд рекомендован организаторами, но не заменяет воспроизводимый запуск из репозитория.
