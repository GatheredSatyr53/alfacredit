# Обученная модель и резервный расчёт

Модель выбирается Scoring:ModelVersion: rules-0.3 (совместимый старый режим, по умолчанию) либо logreg-synthetic-0.1. Scoring:Mode=External вызывает Python, при ошибке использует выбранную встроенную модель; Mode=Rules сразу использует её локально. Имя enum оставлено для совместимости API.

Логистическая регрессия использует src/AlfaCredit.Core/Scoring/logreg-synthetic-0.1.json. Артефакт копируется в output/publish. Scoring:ArtifactPath задаёт необязательный альтернативный путь. Артефакт валидируется при старте: версия, признаки, коэффициенты, положительные масштабы, объяснения и границы A–E. Отсутствующий/повреждённый файл останавливает старт с диагностикой.

При logreg внешние model_version, PD, score и grade проверяются. Несовместимый ответ вызывает резервный расчёт. /health/ready сверяет model_version и artifact_sha256 Python с загруженным локальным артефактом; несовпадение — Unhealthy. Недоступность Python — Degraded (HTTP 200), поскольку локальный расчёт продолжает обслуживать заявки.

Запуск с соседним обновлённым репозиторием ML: задать SCORING_MODEL=logreg-synthetic-0.1 и выполнить docker compose -f docker-compose.yml -f compose.scoring.yml up -d --build --wait. Переменная задаёт одну версию API и Python. Закреплённый старый GHCR-образ rules не содержит новой модели; для неё нужен обновлённый локальный checkout или соответствующий опубликованный образ.

Новый идемпотентный seed-профиль client_reduced / Demo123!, ООО «Развитие», ИНН 7702234567: working-capital 3 млн/24 месяца → около 61/C → 2.4 млн/22.5%, затем обычное подписание и имитация выдачи. Старые пользователи, компании и заявки не изменяются. client_medium при новой модели может получать A; ручного присваивания ему C нет.

Unit-тест LogRegConformanceTests сверяет все 33 контрольных входа Python/sklearn с C#: признаки, PD, logit, score/grade, факторы, warnings и missing_data. LogRegArtifactTests проверяет повреждённые артефакты. HTTP-тесты проверяют несовместимые ответы и выбор правильного fallback. Существующие правила и их эталоны сохраняются.

Форматы заявок/договоров и кредитная политика не меняются; миграций для модели нет. PD относится к модели на синтетике. Вклады факторов — объяснение модели, не причинные эффекты и не точная сумма баллов.
